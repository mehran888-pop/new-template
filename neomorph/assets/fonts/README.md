# فونت‌ها

## فونت‌های داخلی
قالب به‌صورت پیش‌فرض **وزیرمتن (Vazirmatn)** را از Google Fonts بارگذاری می‌کند. سایر فونت‌های آماده:
ایران‌یکان، ایران‌سنس ایکس، استعداد (نیازمند فایل محلی)، Rubik، Playfair Display.

## فونت دلخواه شما
از **تنظیمات نئومورف ← بارگذاری فونت دلخواه** می‌توانید فایل‌های زیر را آپلود کنید:

| پسوند | فرمت CSS |
|-------|----------|
| `.woff2` | woff2 (پیشنهادی) |
| `.woff` | woff |
| `.ttf` | truetype |
| `.otf` | opentype |

نکات:
- برای وزن‌های مختلف، چند فایل را هم‌زمان انتخاب کنید؛ نام فایل باید شامل وزن (مثلاً `IRANSansX-700.woff2`) باشد.
- برای اسلایس ایتالیک، نام فایل شامل `italic` باشد.
- فایل‌های فونت در `wp-content/uploads` ذخیره و با `@font-face` این‌لاین بارگذاری می‌شوند (بدون وابستگی CDN).

## فونت داخلی مخزن
اگر می‌خواهید فونت‌ها را کاملاً آفلاین نگه دارید، فایل‌های وزیرمتن را در همین پوشه قرار دهید و در
`inc/class-enqueue.php` مسیر `google` را حذف و `custom` را جایگزین کنید (یا از بارگذاری فونت دلخواه استفاده کنید).
