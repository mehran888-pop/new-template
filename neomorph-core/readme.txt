افزونه همراه قالب نئومورف: پنل مشتری با OTP، باشگاه مشتریان، فاکتور و لینک پرداخت، تیکت، CRM و اتوماسیون، استخدام مرحله‌ای با امتیازدهی خودکار، اتصال sms.ir، ملی پیامک، بله و تلگرام.

== ماژول‌ها ==
* احراز هویت OTP (sms.ir / ملی پیامک) + ورود/ثبت‌نام
* پنل مشتری: داشبورد، خریدها، مالی و حسابداری، تیکت، باشگاه مشتریان، درخواست مشاوره، پروفایل
* فاکتور حرفه‌ای + لینک پرداخت اختصاصی + درگاه زرین‌پال/آی‌دی‌پی
* باشگاه مشتریان: امتیاز، سطوح، جوایز، رتبه‌بندی
* تیکت پشتیبانی با گفتگوی رشته‌ای
* CRM: دسته‌بندی مشتریان، خدمات انتخابی، پرونده/فرصت، پیگیری
* اتوماسیون: قوانین رویداد→شرط→اقدام (پیامک/بله/تلگرام/ایمیل/امتیاز/سرنخ)
* استخدام مرحله‌ای + امتیازدهی خودکار رزومه + مصاحبه ویدیویی
* یکپارچگی Gravity Forms: ارسال خودکار به CRM + آینه اعلان‌ها
