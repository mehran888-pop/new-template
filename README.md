# نئومورف (Neomorph) — قالب حرفه‌ای وردپرس با سبک نئومورفیسم

قالب وردپرس مدرن با طراحی **نئومورفیسم (Neomorphism)** + افزونه همراه **Neomorph Core** — مناسب کسب‌وکارهای خدماتی و فروشگاهی ایرانی.

### ایده‌های تکمیلی (که اضافه شد)
- 🔐 **OTP امن**: کد ۵ رقمی، کول‌داون ۱۲۰ ثانیه، هش مقایسه زمان‌ایمن، ثبت‌نام خودکار اختیاری
- 💳 **لینک پرداخت عمومی** فاکتور با توکن یکتا (`?nmc-invoice=token`) + دکمه چاپ/PDF + کپی لینک
- 🎁 **سطوح باشگاه** (برنزی→نقره‌ای→طلایی→الماسی) + جوایز قابل تعویض + رتبه‌بندی
- ⚙️ **اتوماسیون با توکن پیام** (`{name} {amount} {invoice}…`) و شرط‌های عددی (`amount>=500000`)
- 📈 **اسکورینگ رزومه**: معیار/وزن/کلیدواژه به‌ازای هر آگهی؛ امتیاز ≥ ۷۰ → ورود خودکار به مرحله مصاحبه ویدیویی
- 🧾 **ارزش مادام‌العمر مشتری (LTV)** در CRM
- 🌙 **نئو تیره** (Dark Neumorphism) با یک کلیک
- ♿ دسترس‌پذیری: skip-link، aria، `prefers-reduced-motion`

## 📦 ساختار مخزن

```
new-template/
├── neomorph/                  # قالب وردپرس (پرزنتیشن)
│   ├── style.css              # هدر قالب
│   ├── functions.php          # بوت‌استرپ + اتوالودر
│   ├── inc/
│   │   ├── options/           # پنل تنظیمات قالب (۱۰ تب)
│   │   ├── elementor/         # ۱۶ ابزارک + کنترل‌های مشترک نئو
│   │   ├── woocommerce/       # لایوت محصول/فروشگاه از تنظیمات
│   │   ├── gravity-forms/     # استایل و چسب فرم‌ها
│   │   └── demo/              # درون‌ریز دمو (JSON های المنتوری)
│   ├── assets/{css,js}/
│   └── languages/
├── neomorph-core/             # افزونه همراه (داده و منطق)
│   ├── src/
│   │   ├── Auth/              # OTP
│   │   ├── Panel/             # پنل مشتری (۷ تب)
│   │   ├── Finance/           # فاکتور + درگاه‌ها
│   │   ├── Loyalty/           # باشگاه مشتریان (جدول امتیاز)
│   │   ├── Tickets/           # تیکت
│   │   ├── Crm/               # مشتریان، سرنخ/پرونده، خدمات
│   │   ├── Automation/        # موتور قوانین رویداد→اقدام
│   │   ├── Recruitment/       # استخدام + اسکورینگ
│   │   ├── Integrations/      # sms.ir، ملی پیامک، بله، تلگرام
│   │   └── GravityForms/      # چسب گراویتی
│   └── assets/
└── docs/                      # مستندات فارسی
```

> **چرا دو پکیج؟** طبق استاندارد وردپرس، داده و قابلیت‌ها (CRM، فاکتور، OTP…) باید در افزونه باشند تا با تعویض قالب از بین نروند. قالب فقط نمایش را مدیریت می‌کند.

## 🚀 نصب سریع

1. **قالب**: پوشه `neomorph/` را به `wp-content/themes/` کپی و فعال کنید.
2. **افزونه**: پوشه `neomorph-core/` را به `wp-content/plugins/` کپی و فعال کنید.
3. **پیش‌نیازها**: Elementor (رایگان)، WooCommerce، Gravity Forms (اختیاری).
4. **دمو**: منوی «تنظیمات نئومورف ← دموی اولیه» ← «شروع نصب دمو» — همه صفحات با یک کلیک ساخته می‌شوند.
5. **اتصال‌ها**: «نئومورف کور ← تنظیمات اتصال‌ها» — کلیدهای sms.ir / ملی پیامک / بله / تلگرام و درگاه پرداخت.
6. **شخصی‌سازی**: «تنظیمات نئومورف» — فونت، رنگ، شدت سایه‌های نئو، چیدمان‌ها.

## 🧩 ابزارک‌های المنتور (دسته «نئومورف»)

| ابزارک | چیدمان‌ها |
|--------|-----------|
| هیرو | دو ستونه / وسط‌چین / جمع‌وجور + شکل هندسی |
| خدمات | گرید / دایره‌ها / لیست / تب‌دار |
| تیم ما | کارت‌ها / پرتره دایره‌ای / نوار افقی |
| درباره ما | تصویر کنار متن / روی هم / تمرکز آمار + شمارنده |
| تماس با ما | اطلاعات+فرم / کارت‌ها بالا / حداقلی (گراویتی یا داخلی) |
| شبکه‌های اجتماعی | کپسول / دایره / ردیف متنی |
| نمایش مقالات | کارت / لیست / برجسته+کناری / ماسونری |
| محصولات | ویژه/پرفروش/جدید/دسته/شناسه + سبک کارت |
| هدر | کلاسیک / وسط‌چین / مینیمال / شناور + سبد/ورود/CTA |
| فوتر | ۳ ستونه / ۲ ستونه / تکی / مینیمال + خبرنامه گراویتی |
| سبد خرید حرفه‌ای | مینی کشویی / جدول کامل / جمع‌کل |
| فرم ورود | OTP / رمز + کارت / دوستونه / درون‌خطی |
| فرم ثبت‌نام | فیلدهای قابل انتخاب + پیام باشگاه |
| باشگاه مشتریان | کارت امتیاز / سطوح / جوایز / رتبه‌بندی |
| پنل مشتریان | سایدبار / تب / کارتی |
| استخدام | کارت / آکاردئون / روند مرحله‌ای / جدول |

همه ابزارک‌ها **کنترل استایل نئومورف** دارند: رنگ پس‌زمینه، گردی گوشه، چیدمان سطح (برآمده/فرورفته/تخت/کپسولی)، فاصله‌ها، تایپوگرافی، سایه سفارشی.

## 🗃 معماری داده

| CPT / جدول | نقش |
|------------|-----|
| `nmc_invoice` | فاکتور (آیتم‌ها، وضعیت، توکن پرداخت) |
| `nmc_ticket` | تیکت + رشته پیام‌ها |
| `nmc_case` | پرونده CRM / فرصت با مرحله و پیگیری |
| `job` + `job_type` | موقعیت شغلی + نوع همکاری |
| `nmc_application` | رزومه + امتیاز خودکار + مرحله |
| `nmc_consult` | درخواست مشاوره/پشتیبانی |
| `crm_segment` / `crm_service` | دسته مشتریان / خدمات انتخابی |
| `wp_nmc_points` | دفتر کل امتیاز باشگاه |
