# راهنمای نصب و راه‌اندازی نئومورف

## ۱. پیش‌نیازها

| نرم‌افزار | نسخه | الزام |
|-----------|------|-------|
| وردپرس | ۶.۰ به بعد | ✅ |
| PHP | ۷.۴ به بعد (۸.x توصیه می‌شود) | ✅ |
| MySQL / MariaDB | ۵.۷+ | ✅ |
| Elementor (رایگان) | آخرین نسخه | ✅ |
| WooCommerce | آخرین نسخه | ✅ |
| Neomorph Core (همراه مخزن) | ۱.۰ | ✅ |
| Gravity Forms | ۲.۶+ | اختیاری |
| گواهی SSL | — | ✅ (پرداخت و OTP) |

## ۲. نصب

1. پوشه `neomorph` را در `wp-content/themes/` قرار دهید و از **ظاهر ← پوسته‌ها** فعال کنید.
2. پوشه `neomorph-core` را در `wp-content/plugins/` قرار دهید و از **افزونه‌ها** فعال کنید.
3. هشدار «پیش‌نیازها» در پیشخوان، وضعیت افزونه‌ها را نشان می‌دهد.

## ۳. نصب دموی اولیه

از منوی **تنظیمات نئومورف ← دموی اولیه**:

- ☑ ساخت صفحات با محتوای المنتور (صفحه اصلی، درباره ما، ارتباط با ما، مقالات، استخدام، ورود، ثبت‌نام، مصاحبه ویدیویی، مشاوره)
- ☑ منوهای نمونه (اصلی/موبایل/فوتر)
- ☑ تنظیمات پیش‌فرض قالب (وزیرمتن + پالت نئو)
- ☑ صفحات ووکامرس + محصول نمونه

صفحات «پنل مشتریان» و «پرداخت فاکتور» نیز با تمپلیت اختصاصی ساخته و در تنظیمات قالب مپ می‌شوند.

## ۴. تنظیمات اتصال‌ها (نئومورف کور ← تنظیمات اتصال‌ها)

### پیامک
- **sms.ir**: کلید API (X-API-KEY)، شماره خط، کد پترن OTP (برای ارسال کد تأیید قالب‌دار).
- **ملی پیامک**: نام کاربری/رمز REST، شماره خط، کد پترن.
- سامانه فعال را انتخاب کنید. پیامک‌های OTP و اعلان‌ها از این مسیر ارسال می‌شوند.

### بله و تلگرام
- توکن ربات + شناسه چت/کانال ادمین. اعلان‌های مدیریتی (فاکتور جدید، تیکت جدید، خلاصه روزانه) روی هر دو (در صورت تنظیم) می‌رود.
- مشتری می‌تواند در تب پروفایل پنل، شناسه چت بله/تلگرام خود را وارد کند تا اعلان‌های شخصی را آنجا بگیرد.

### درگاه پرداخت
- **زرین‌پال**: مرچنت کد (و حالت سندباکس در صورت نیاز).
- **آی‌دی‌پی**: کلید API.
- **دستی**: کارت‌به‌کارت + تأیید دستی فاکتور توسط ادمین.

## ۵. تنظیمات قالب (تنظیمات نئومورف)

| تب | چه چیزی تنظیم می‌شود |
|----|----------------------|
| تایپوگرافی | فونت متن/تیتر (وزیرمتن، ایران‌یکان، استعداد، Rubik، Playfair یا **فونت دلخواه آپلودی**) |
| رنگ‌بندی | پس‌زمینه، متن، اکشن، مکمل |
| موتور نئومورفیسم | گردی گوشه، فاصله سایه، نرمی سایه، نئو روشن/تیره |
| چیدمان | تمام‌عرض/جعبه‌ای، عرض محتوا، سایدبار، بردکرامب |
| هدر و فوتر | ۳ چیدمان هدر + چسبان، ۳ چیدمان فوتر |
| مقالات و آموزش | گرید/لیست/ماسونری، طول خلاصه، مقاله تکی |
| فروشگاه | ستون‌ها، ۴ چیدمان صفحه محصول، سبک کارت، حالت کاتالوگ، واحد پول |
| استخدام | متن معرفی، عنوان فرم، سبک ویزارد |
| مصاحبه ویدیویی | عنوان، منبع ویدیو (کتابخانه/آپارات/لینک) |
| تماس و شبکه‌ها | تلفن/ایمیل/آدرس + شبکه‌های اجتماعی (تکرارشونده) |
| صفحات سیستم | مپ صفحات پنل/ورود/ثبت‌نام/فاکتور/فروشگاه/مقالات |

### بارگذاری فونت دلخواه
تب «بارگذاری فونت دلخواه» ← نام خانواده + نام انگلیسی + فایل‌های `woff2/woff/ttf` (برای وزن‌ها چند فایل با هم؛ نام فایل شامل وزن مثل ۴۰۰/۷۰۰ باشد) ← سپس در تب تایپوگرافی انتخاب کنید.

## ۶. صفحات پنل مشتری

- قالب «**پنل مشتریان (Neomorph)**» را روی صفحه پنل بگذارید (دمو خودکار انجام می‌دهد) یا شورت‌کد `[neomorph_panel]` را در هر صفحه‌ای بگذارید.
- با ابزارک «فرم ورود حرفه‌ای» / «فرم ثبت‌نام حرفه‌ای» صفحه‌های auth را بسازید.
- جریان OTP: شماره → کد ۵ رقمی (۱۲۰ ثانیه کول‌داون) → ورود/ثبت‌نام خودکار (قابل غیرفعال‌سازی) → هدایت به پنل.

## ۷. سیستم استخدام

1. در **نئومورف کور ← استخدام** یک «موقعیت شغلی» بسازید.
2. در جعبه «معیارهای امتیازدهی» برای هر آگهی: معیار، وزن (جمع ~۱۰۰) و کلیدواژه‌ها را تعیین کنید.
3. فرم `[neomorph_apply job="ID"]` (یا ابزارک استخدام) را بگذارید — ویزارد ۵ مرحله‌ای (هویتی، سوابق، سؤالات، ویدیو، بازبینی).
4. امتیاز خودکار از تطابق کلیدواژه‌های متن رزومه با معیارها محاسبه می‌شود؛ امتیاز ≥ ۷۰ (قابل فیلتر) ورود خودکار به مرحله **مصاحبه ویدیویی** + پیامک به متقاضی.

## ۸. اتوماسیون پیشنهادی

در **نئومورف کور ← قوانین اتوماسیون** نمونه‌های آماده داخل صفحه هست. مثال:

| رویداد | شرط | اقدام |
|--------|-----|-------|
| `invoice_paid` | — | پیامک به مشتری: «خرید شما انجام شد {name}» |
| `invoice_created` | `amount>=5000000` | تلگرام ادمین: «فاکتور {invoice} مبلغ {amount}» |
| `ticket_created` | — | بله ادمین: «تیکت جدید {title}» |
| `case_stage_changed` | `stage=won` | ۱۰۰ امتیاز باشگاه |
| `apply_received` | — | تلگرام ادمین: «رزومه جدید» |

## ۹. عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| کد OTP نمی‌آید | تنظیمات sms.ir/ملی پیامک + کد پترن؛ در `WP_DEBUG` کد در پاسخ JSON برمی‌گردد |
| ابزارک‌های نئومورف در المنتور نیست | Elementor فعال است؟ `Neomorph\Elementor` ری‌جیستر می‌شود روی `elementor/widgets/register` |
| لینک پرداخت ۴۰۴ | صفحه «پرداخت فاکتور» را در تنظیمات قالب/کور مپ کنید |
| استایل نئو اعمال نشد | `wp_enqueue` قالب بعد از child themeها؛ کش را پاک کنید |
